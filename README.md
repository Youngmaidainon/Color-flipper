# Color Flipper

โปรเจกต์เว็บแอปพลิเคชันขนาดเล็กสำหรับสุ่มสีพื้นหลัง พร้อมแสดงรหัสสีในรูปแบบ Hex และ RGB รองรับสองโหมดคือสีแบบสุ่ม (Hex) และสีแบบมีชื่อ (Named Colors)

---

## คุณสมบัติ

- สุ่มสีพื้นหลังใหม่ทุกครั้งที่กดปุ่ม Generate หรือกด Spacebar
- แสดงรหัสสีทั้งในรูปแบบ Hex Code และ RGB
- สลับโหมดระหว่าง Hex (สีสุ่มทั่วไป) กับ Named Colors (สีที่มีชื่อกำหนดไว้)
- คัดลอกรหัสสีไปยัง Clipboard ด้วยปุ่ม Copy
- บันทึกสีโปรดลง LocalStorage ด้วยปุ่ม Save
- ตัวอักษรบนหน้าจอปรับสีอัตโนมัติ (ดำหรือขาว) ให้ตัดกับพื้นหลัง

## การใช้งานปุ่มต่างๆ

| ปุ่ม | การทำงาน |
|---|---|
| Mode : Hex / Named | สลับโหมดการแสดงผลสี |
| Generate | สุ่มสีใหม่ |
| Copy | คัดลอกรหัสสีที่แสดงอยู่ไปยัง Clipboard |
| Save | บันทึกสีปัจจุบันลง LocalStorage |
| Spacebar | สุ่มสีใหม่ (ทางลัดจากคีย์บอร์ด) |

---

## โหมดการทำงาน

**Hex Mode**
สุ่มรหัสสี Hex แบบสุ่ม 16 ล้านสี แสดงผลในรูปแบบ `#rrggbb`

**Named Mode**
สุ่มสีจากรายการสีที่กำหนดชื่อไว้ล่วงหน้า เช่น Tomato, SteelBlue, Gold และอื่นๆ รวม 10 สี

## หมายเหตุ

ฟีเจอร์บันทึกสีโปรด (Save) ใช้ LocalStorage ของเบราว์เซอร์ ข้อมูลจะถูกเก็บไว้ในเครื่องของผู้ใช้และจะหายไปหากล้างข้อมูลเบราว์เซอร์
